電解質・原子の成り立ち・イオン ★☆☆

「化学変化とイオン」の入り口です。電解質と非電解質のちがいを確認し、原子の構造からイオンの成り立ちを学び、電離式まで書けるようになりましょう。

1電解質と非電解質
📖 説明
0:00.0

水に溶かしたとき電流を流す物質を「電解質」といいます。食塩（塩化ナトリウム）・塩酸・水酸化ナトリウムなどが代表例です。

一方、水に溶かしても電流を流さない物質を「非電解質」といいます。

非電解質の代表例は「砂糖」と「エタノール」の2つです。必ず覚えましょう。

なぜ電解質の水溶液は電流が流れるのでしょうか？ 電解質が水溶液に溶けると「イオン」が生じ、そのイオンが電子を受け渡しするために電流が流れます。

▲ 水溶液の電気伝導性を調べる実験装置
🔬 実験で確かめよう！
塩化ナトリウム水溶液 → 電球が光る（電流が流れた = 電解質）
砂糖水・エタノール水溶液 → 電球が光らない（電流が流れない = 非電解質）
★ 覚えよう！
  • 電解質 …… 水に溶けて電流を流す物質（例：NaCl・HCl・NaOH）
  • 非電解質 …… 水に溶けても電流を流さない物質
  • 非電解質の例 → 砂糖・エタノール（この2つは必須！）
  • 電流が流れる理由 → 電解質が溶けてイオンが生じ、電子を受け渡しするから
📚 語群 ― タップして単語を選び、空欄をタップ！
✏️ ミニテスト（全3問）
問1水に溶かしたとき電流を流す物質を「電解質」という。
○ 正解です。食塩・塩酸・水酸化ナトリウムなどが電解質の代表です。
問2砂糖を水に溶かすと電流が流れる。
× 砂糖は非電解質なので、水に溶かしても電流は流れません。エタノールも同様に非電解質です。
問3電解質の水溶液に電流が流れる理由として正しいものはどれか。
正解はウ。電解質が水中でイオンに分かれ（電離）、そのイオンが電子を受け渡しすることで電流が流れます。

2原子の成り立ち
📖 説明
0:00.0

すべての物質は「原子」から成り立っています。

原子の真ん中には「原子核」があり、その周りを－の電荷を帯びた「電子」が高速で回っています。

原子核は、＋の電気を帯びた「陽子」と、電気的に中性な「中性子」から成り立っています。

▲ ヘリウム(He)原子のモデル図
📋 原子を構成する粒子
陽子
原子核の中にある。＋の電荷をもつ。
中性子
原子核の中にある。陽子と同じ質量だが電気的に中性。
電子
原子核のまわりを回る。－の電荷をもつ。

【重要】すべての原子において、「陽子」の数と「電子」の数は等しくなっています。そのため原子全体では＋と－が打ち消し合い、電気的に「中性」です。

★ 覚えよう！
  • 原子核 ＝ 陽子（＋） ＋ 中性子（中性）
  • 電子（－）…… 原子核のまわりを回る
  • 陽子の数 ＝ 電子の数 → 原子全体は電気的に中性
  • 陽子1個と電子1個のもつ電荷の量は等しい
📚 語群 ― タップして単語を選び、空欄をタップ！
✏️ 確認問題（全4問）
問1原子核は、陽子と中性子から成り立っている。
○ 正解です。原子核の中には陽子（＋）と中性子（中性）があります。
問2原子の中の電子の数は、陽子の数より必ず多い。
× 陽子の数と電子の数は等しいです。だから原子全体は電気的に中性なのです。
問3原子核のまわりを回っている、－の電荷をもつ粒子は何か。
正解はイ：電子。電子は－の電荷をもち、原子核のまわりを高速で回っています。
問4原子が電気的に中性である理由として正しいものはどれか。
正解はエ。陽子（＋）の数 ＝ 電子（－）の数なので、電荷が打ち消し合って全体では中性になります。

3イオン ― 陽イオンと陰イオン
📖 イオンとは
0:00.0

原子が電子を失ったり得たりして電気を帯びたものを「イオン」といいます。

原子が電子を失うと、陽子の数が電子の数より多くなるため「陽イオン」（＋の電荷）になります。

原子が電子を得ると、電子の数が陽子の数より多くなるため「陰イオン」（－の電荷）になります。

▲ 原子がイオンになるしくみ
★ 覚えよう！
  • イオン …… 原子が電子を失ったり・得たりして電気を帯びたもの
  • 電子を失う → 陽子 ＞ 電子 → 陽イオン（＋）
  • 電子を得る → 電子 ＞ 陽子 → 陰イオン（－）
📚 語群 ― タップして単語を選び、空欄をタップ！
📖 陽イオン（Na の例）
0:00.0

ナトリウム(Na)原子は陽子が11個・電子が11個あります。

電子を1個失うと → 陽子11個、電子10個 → ＋1の電荷を帯びた「陽イオン」になります。これをナトリウムイオン（Na+）といいます。

陽イオンのポイント

原子が電子を失う
→ 陽子 ＞ 電子
→ ＋の電荷を帯びる
→ 陽イオン（Na+ など）

★ 陽イオンまとめ
  • 電子を失う → ＋の電荷 → 陽イオン
  • Na → Na+（電子1個失う）
  • Cu → Cu2+（電子2個失う）
  • H → H+（電子1個失う）
📚 語群 ― タップして単語を選び、空欄をタップ！
📖 陰イオン（Cl の例）
0:00.0

塩素(Cl)原子は陽子が17個・電子が17個あります。

電子を1個得ると → 陽子17個、電子18個 → －1の電荷を帯びた「陰イオン」になります。これを塩化物イオン（Cl−）といいます。

陰イオンのポイント

原子が電子を得る
→ 電子 ＞ 陽子
→ －の電荷を帯びる
→ 陰イオン（Cl− など）

★ 陰イオンまとめ
  • 電子を得る → －の電荷 → 陰イオン
  • Cl → Cl−（電子1個もらう）
  • OH → OH−（電子1個もらう）
  • SO4 → SO42−（電子2個もらう）

フラッシュカード ＋ 4択クイズ
✏️ 確認問題（全4問）
問1原子が電子を失うと陰イオンになる。
× 電子を失うと＋の電荷を帯びて陽イオンになります。陰イオンは電子を得たときです。
問2ナトリウム原子(Na)が電子を1個失ったときのイオン式はどれか。
正解はア：Na+。電子を1個失うので＋1の電荷を帯びた陽イオンになります。
問3塩素原子(Cl)が電子を1個得たときのイオン式はどれか。
正解はウ：Cl−。電子を1個得るので－1の電荷を帯びた陰イオン（塩化物イオン）になります。
問4次のうち陽イオンでないものはどれか。
正解はイ：OH−（水酸化物イオン）。これは－の電荷をもつ陰イオンです。ア・ウ・エはすべて陽イオンです。

4電離と電離式
📖 説明
0:00.0

電解質が水中で陽イオンと陰イオンに分かれることを「電離」といいます。電離後、全体の電荷の和は必ず 0 になります。

電離のようすをイオン記号で表した式を「電離式」といいます。矢印（→）の左に元の物質、右に生じたイオンを書きます。

電解質電離式
塩化水素（塩酸）HCl → H+ ＋ Cl−
塩化ナトリウムNaCl → Na+ ＋ Cl−
水酸化ナトリウムNaOH → Na+ ＋ OH−
塩化銅CuCl2 → Cu2+ ＋ 2Cl−
硫酸銅CuSO4 → Cu2+ ＋ SO42−
水酸化バリウムBa(OH)2 → Ba2+ ＋ 2OH−
硫酸H2SO4 → 2H+ ＋ SO42−
💡 電荷バランスのチェック方法
例）CuCl2 → Cu2+ ＋ 2Cl−
右辺の電荷合計：(＋2) ＋ 2×(－1) ＝ 0 ✓
★ 電離式の書き方ポイント！
  • 電離 …… 電解質が水中で陽イオンと陰イオンに分かれること
  • 矢印の右辺：生じたイオンの電荷の合計 ＝ 0
  • CuCl2 → Cu2+ ＋ 2Cl−（Clが2個！）
  • Ba(OH)2 → Ba2+ ＋ 2OH−（OHが2個！）
  • H2SO4 → 2H+ ＋ SO42−（Hが2個！）
📚 語群 ― タップして単語を選び、空欄をタップ！
✏️ 電離式 確認問題（全5問）
問1塩化ナトリウムの電離式は「NaCl → Na+ ＋ Cl−」である。
○ 正解です。NaCl は Na+ と Cl− に電離します。(＋1)＋(－1)＝0 ✓
問2塩化銅 CuCl2 の電離式として正しいものはどれか。
正解はウ。銅イオンは Cu2+、電荷バランスから Cl− が2個必要。(＋2)＋2×(－1)＝0 ✓
問3水酸化バリウム Ba(OH)2 の電離式として正しいものはどれか。
正解はイ。Ba2+ と OH− が2個に電離。(＋2)＋2×(－1)＝0 ✓
問4硫酸 H2SO4 の電離式として正しいものはどれか。
正解はア。H が2個あるので水素イオンが2個できます。2×(＋1)＋(－2)＝0 ✓
問5電離の説明として正しいものはどれか。
正解はエ。電離とは「電解質が水中で陽イオンと陰イオンに分かれること」です。熱や電気ではなく、水に溶けることで自然に起こります。

5酸とアルカリ
📖 説明
0:00.0

🔴 酸の性質

水に溶けたときに電離して水素イオン（H+）を生じる物質を酸という。

  • 酸味をもつ。
  • 青色リトマス試験紙を赤色に変える。
  • 鉄やマグネシウムと反応すると気体の水素が発生する。
【例】塩酸の電離：HCl  →  H+ ＋ Cl−

🔵 アルカリの性質

水に溶けたときに電離して水酸化物イオン（OH−）を生じる物質をアルカリという。

  • 苦みをもつ。ぬるぬるする。
  • 赤色リトマス試験紙を青色に変える。
【例】水酸化ナトリウムの電離：NaOH  →  Na+ ＋ OH−
★ まとめ
  • 酸：H+ を生じる ／ 青→赤 ／ 水素発生（金属と反応）
  • アルカリ：OH− を生じる ／ 赤→青

🔬 実験
0:00.0

🧪 電気泳動実験（イオンの移動）

食塩水をしみこませたろ紙に、青・赤のリトマス試験紙を置いて電圧をかける実験。

結果と考察

① 塩酸（HCl）をたらした場合
HCl → H+ ＋ Cl−
H+（陽イオン）は−極の方向へ移動する。
→ b（青リトマス・－側）が赤色に変わる ＝ 酸性
② 水酸化ナトリウム（NaOH）をたらした場合
NaOH → Na+ ＋ OH−
OH−（陰イオン）は＋極の方向へ移動する。
→ c（赤リトマス・＋側）が青色に変わる ＝ アルカリ性
③ 食塩水（NaCl）をたらした場合
NaCl → Na+ ＋ Cl−
H+ も OH− も生じないため、リトマスの色は変化しない。
★ ポイント
  • 陽イオン（＋）は －極 へ引き寄せられる
  • 陰イオン（－）は ＋極 へ引き寄せられる
  • 酸性の原因 ＝ H+、アルカリ性の原因 ＝ OH−

✏️ 酸とアルカリ 確認問題（全6問）
問1酸は水に溶けて水素イオン（H+）を生じる物質である。
○ 正解です。H+ を生じるのが酸の定義です。
問2アルカリは青色リトマス試験紙を赤色に変える。
× アルカリは赤→青です。青→赤に変えるのは酸です。
問3塩酸に鉄を入れると水素が発生する。
○ 正解です。酸（H+）は金属と反応して水素を発生させます。
問4電気泳動実験で、塩酸を中央のろ紙にたらした。色が変わるのはどれか。
正解はイ：b。H+（陽イオン）は－極に引き寄せられ、－側にある青リトマス紙（b）を赤に変えます。
問5電気泳動実験で、水酸化ナトリウム水溶液をたらした。色が変わるのはどれか。
正解はウ：c。OH−（陰イオン）は＋極に引き寄せられ、＋側にある赤リトマス紙（c）を青に変えます。
問6アルカリ性の原因となるイオンはどれか。
正解はア：水酸化物イオン OH−。アルカリ性の原因は OH− です。H+ は酸性の原因。
